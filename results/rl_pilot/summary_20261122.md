## Reading

- **The LoRA does not transfer.** Against its own control (same pod, same calls) it finds 12 fewer known errors (64 ->
  52) with as many false findings, while it is perfect on the synthetic close-ups: it learned the synthetic drawings,
  not the real ones. Full RL on synthetic questions, as planned, is stopped.
- **Few-shot is promising, not proven.** Its examples are 14 of the user's marks, and those marks are on calls of the
  same exam sets (e.g. `after/real09/L1#text|plausibility|P3:r_L1_antre`), so its drop in false findings is partly the
  model being shown the answer; `vt-score` does not yet score only the other fold. The known errors (73, no id in
  common with the examples) rose 54 -> 61.
- **The BF16 base finds more than the FP8 model** (64 against 54, images only, different pods): worth one measured A/B
  with the drawing text on before any switch.
- The exam ran without the drawing text (`CRITIC_VECTOR_TEXT` was not set in rl_pilot.sh), so no arm is compared with
  today's default (66/73) directly.
